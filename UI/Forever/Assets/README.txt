PoisonFlow Forever UI – prototype asset pack

These TGA files are cropped from the generated concept atlas, NOT original layered assets.
Some sprites contain dark backgrounds, slight clipping, or baked-in ornamentation.
Alpha on smaller decorations is approximated. Review in-game before using in a release.
Do not stretch full window frames; use them only for mockups. Prefer 9-slice or native WoW textures for scalable UI.

Recommended reusable UI Lua components:
Theme.lua (colors, sizes, spacing, asset paths)
Window.lua (header, background, frame)
Panel.lua (reusable panel)
TabBar.lua (Gifte / Warnungen)
Button.lua, Checkbox.lua, Slider.lua
PoisonSlot.lua, WeaponPanel.lua, WarningRow.lua

Development command: /pf new; keep original /pf intact.
